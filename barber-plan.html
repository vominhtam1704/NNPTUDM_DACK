💳 Tích hợp SePay MBBank

Luồng thanh toán QR Code

Bước 1: Tạo đơn thanh toán
Client gọi POST /api/payments/create với reservationId. Server tạo payment record, gọi SePay API tạo QR.
Bước 2: Hiển thị QR MBBank
Server trả về qrCodeUrl + amount + transactionId. FE hiển thị QR, polling mỗi 3 giây kiểm tra status.
Bước 3: Webhook callback
SePay gọi POST /api/payments/webhook sau khi khách quét QR. Server verify signature, update status = "paid", reservation = "confirmed".
Bước 4: Xác nhận & thông báo
Tạo message thông báo cho khách + barber. FE polling nhận được status "paid" → redirect trang thành công.

Code tham khảo: SePay Webhook

// routes/payments.js router.post('/webhook', async (req, res) => { const { transferAmount, transactionID, content } = req.body; // 1. Xác minh chữ ký SePay const sig = req.headers['x-sepay-signature']; if (!verifySig(sig, req.body)) { return res.status(401).json({err:'Invalid sig'}); } // 2. Tìm payment theo transactionID const payment = await Payment.findOne( { transactionId: transactionID } ); // 3. Cập nhật trạng thái payment.status = 'paid'; payment.paidAt = new Date(); await payment.save(); // 4. Cập nhật reservation await Reservation.findByIdAndUpdate( payment.reservationId, { status: 'confirmed' } ); res.json({ success: true }); });
⚠️ Lưu ý: Cần cấu hình ngrok (development) hoặc domain thật để SePay gọi được webhook. Lưu SEPAY_API_KEY và ACCOUNT_NUMBER vào .env

Trả về { qrCodeUrl, transactionId, amount, expiredAt } GET /api/payments/:id - verifyToken, trả thông tin payment + reservation POST /api/payments/webhook - KHÔNG cần verifyToken (SePay gọi trực tiếp) - Verify: kiểm tra header x-sepay-signature hoặc apikey query param - Body từ SePay gồm: transferAmount, transactionID, content (thường chứa transactionId mình tạo) - Logic: parse content tìm transactionId, update payment.status='paid', update reservation.status='confirmed', gửi message thông báo cho customer - Luôn trả { success: true } để SePay không retry GET /api/payments/report (admin only) - Query: period(day/week/month/year), startDate, endDate - Trả: totalRevenue, count, groupBy method, top barbers by revenue **Env vars cần:** SEPAY_API_TOKEN, BANK_ID, ACCOUNT_NO, ACCOUNT_NAME, SEPAY_WEBHOOK_SECRET Viết đầy đủ với error handling, comments tiếng Việt, format response chuẩn { success, data, message }.
Prompt 5 Tạo utils/uploadHandler.js — Multer Config
